SOURCES / AUTHORIZATION

Dữ liệu có căn cứ.

Mọi nguồn phải có provenance rõ ràng. VOIDSCAN 2.0 khởi động với dữ liệu trống, không sử dụng tập CSV của năm trước.

⇧

Nhập dữ liệu mới (tùy chọn)

Chỉ nhập CSV mà bạn có quyền sử dụng. Hỗ trợ bản xuất có cột Profile ID và Profile Name. Việc nhập là thủ công, không bắt buộc.

OFFICIAL PROVIDER

Meta Graph API

VOIDSCAN hỗ trợ META_USER_ACCESS_TOKEN để đọc danh sách Page bạn quản trị bằng /me/accounts, hoặc META_PAGE_ACCESS_TOKEN để kiểm tra một Page. Chỉ thiết lập token trong PowerShell trên máy chạy backend, không dán token vào chat hoặc trình duyệt. Quyền Page và quyền đọc comment vẫn phải được Meta cấp.

RESEARCH / PLANNED

Mạng lưới phối hợp

Đối chiếu tài khoản, nội dung, thời gian trên nhiều bài đăng. Ước lượng ngưỡng theo phân phối dữ liệu thực thay vì áp một ngưỡng tùy ý cho mọi cộng đồng.
